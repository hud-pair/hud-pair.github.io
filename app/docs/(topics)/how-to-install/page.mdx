## Before you start

PAIR is built as a **static Next.js site** with a separate data layer behind it, so "installing"
means two things: getting the site running, and pointing it at a portfolio. If you only need to
browse the public site, you can skip straight to [How to use](/docs/how-to-use).

## Running the site locally

1. Clone the repository and install dependencies with `npm install`.
2. Start the dev server with `npm run dev`.
3. Open `http://localhost:3000` — you should see the PAIR homepage.

This gives you the marketing site and docs. The dashboard itself (property lists, EPC lookups,
Explorer recommendations) is a separate authenticated app connected to your portfolio's data.

### Connecting a portfolio

Once you have credentials, the dashboard reads EPC and portfolio data from your housing
association's export. **Together Housing Group's pilot portfolio** — 6,867 homes across
Pendle — is the reference dataset used throughout this documentation and in our
[case studies](/case-studies).

## Troubleshooting

If the dashboard loads but shows no properties, the most common cause is a mismatched export
format. Check that your EPC export includes SAP score, classification, hot water, secondary
heating, and wall type — those five fields drive most of what Explorer can tell you, covered in
[How to analyse](/docs/how-to-analyse).
